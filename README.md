# 🤖 StudyBuddy AI

StudyBuddy AI is a prototype AI-powered academic assistant designed for both students and teachers.  
It helps students with learning support while enabling teachers to track progress, manage assignments, and identify weak areas.

---

## 🚀 Features

### 👩‍🎓 Student Features
- Ask academic questions and get answers  
- Get study guidance and learning support  
- Interactive command-line interface  

### 👩‍🏫 Teacher Features
- Track student progress  
- Upload and manage assignments  
- Identify weak topics of students  
- Monitor classroom performance  

---

## 🛠 Tech Stack
- Python  
- Basic AI/ML concepts  
- Command Line Interface (CLI)

## ⚙️ Installation & Setup

### 1. Clone the repository git clone 
https://github.com/anshikapandey23-arch/studybuddy-ai.git

### 2. Navigate to the project folder

cd studybuddy-ai


### 3. Install dependencies

pip install -r requirements.txt


### 4. Run the project

python studybuddy_ai.py
